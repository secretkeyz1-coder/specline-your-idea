3 · Inti 1-Prompt: Loop Eksekusi Otonom

Sekali dijalankan, daemon memakan board dari atas sampai habis. Manusia tidak melakukan apa pun di tengah jalan.

↺ LOOP — berputar otomatis per task
  1. 1
    Satu prompt memulai segalanya

    sdd-agent connect di laptop (atau 1 prompt ke Claude Code via MCP https://vps/mcp) — tidak ada perintah lain.

  2. 2
    VPS memilih task berikutnya

    dispatch-next: task READY prioritas tertinggi yang tidak terblokir DAG. Yang terblokir dilewati, bukan error.

  3. 3
    Claim + lease + heartbeat

    Klaim atomik; heartbeat otomatis menjaga lease tetap hidup selama pengerjaan.

  4. 4
    Drive AI lokal di repo kamu

    Daemon menulis file work order → menjalankan claude / codex / gemini di direktori repo.

  5. 5
    Verifikasi = bukti

    Perintah verifikasi dari kontrak dijalankan; hasil PASSED/FAILED dilaporkan ke VPS sebagai evidence (C2).

  6. 6
    Submit → policy BATCH_REVIEW

    Task lolos ke DONE dengan flag unreviewed — tidak macet menunggu review per task.

  7. 7
    Loop balik ke langkah 2

    Task dependen yang tadi terblokir kini terbuka. Berlanjut sampai board kosong.

↺ board kosong → lanjut ke Review Batch manusia (langkah 08)

4 · Penutup: Review Batch & Gerbang Konvergensi

08

Review batch manusia satu sesi review

Summaries + diff + evidence ditampilkan kolektif; kamu setujui atau buka bug (bug → task perbaikan otomatis).

09

Convergence audit (C18) gate

AI merekonsiliasi implementasi vs spesifikasi: blocking findings, blocking bugs, incomplete tasks.

10

Feature COMPLETE

Gate lolos → fitur dikunci. Temuan audit bisa 1-klik menjadi task perbaikan baru → masuk loop lagi.
