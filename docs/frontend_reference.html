Overview

Agentic SDD Planner

Website yang mengubah high-level idea menjadi planning yang cukup jelas untuk dikerjakan AI coding agent. Sistem menggali kebutuhan lewat pertanyaan adaptif, menyusun specification, memilih atau menerima tech stack, lalu memecah pekerjaan menjadi task atomic.

Prinsip utama: user tidak perlu melihat seluruh detail teknis sekaligus. Informasi muncul secara progresif sesuai tahap planning.

Outcome utama

  • User dapat memulai hanya dari satu paragraf ide.
  • AI berhenti bertanya ketika requirement readiness sudah cukup.
  • Setiap atomic task mempunyai objective, scope, acceptance criteria, verification, dan prompt agent.
  • Status eksekusi dapat disinkronkan melalui CLI atau MCP.

Tech stack

SvelteKit + TypeScript untuk frontend, Bun + Elysia untuk backend, Drizzle ORM dan PostgreSQL untuk data.

TASK-084 · Work order

Implement atomic task claim endpoint

Satu task, satu outcome yang bounded, satu hasil yang bisa diverifikasi.

Objective

Buat endpoint claim yang atomic sehingga dua agent tidak bisa mengambil task READY yang sama secara bersamaan.

Acceptance criteria

✓
READY task dapat di-claim oleh executor yang authorized.
✓
Claim kedua secara concurrent mendapat conflict dan tidak membuat run duplikat.
✓
Owner, run ID, dan lease expiry tersimpan.
✓
Test membuktikan hanya satu claim yang menang.
